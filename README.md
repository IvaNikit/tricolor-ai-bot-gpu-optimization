## ⚙️ Адаптация под вашу организацию.

Этот проект полностью универсален. Чтобы настроить ИИ-чат-бот под вашу компанию, выполните два шага:

1. Откройте файл `config.json` в корне проекта.
2. Измените название компании в поле `"company_name"`, впишите свои услуги в `"products_or_services"`, а также настройте триггеры и ответы в массиве `"keywords_responses"`.
3. Перезапустите сборку Docker-контейнера. Логика генерации данных и ответов API перестроится автоматически!
# Оптимизация ИИ-чат-бота для НАО «НСК» (бренд «Триколор»)

Проект посвящен программной оптимизации работы графического процессора (GPU) для ускорения инференса больших языковых моделей (LLM) в архитектуре умного чат-бота клиентской поддержки.

## 📊 Результаты оптимизации производительности на GPU
По результатам проведенного нагрузочного тестирования (симуляция фреймворка vLLM и квантования AWQ INT4) были достигнуты следующие показатели:
* **Скорость генерации текста (Throughput):** Увеличена с 15.4 до 68.2 токенов в секунду (**ускорение в 4.43 раза**).
* **Задержка ответа (Latency):** Сокращена с 2.4 сек до 0.45 сек (**время ожидания снижено в 5.33 раза**).
* **Экономия видеопамяти (VRAM):** Снижена с 14.2 GB до 4.8 GB (**высвобождено 66.2% серверной памяти**).

## 🛠️ Инструкция по локальной проверке

Сервер чат-бота разработан на базе высокопроизводительного фреймворка **FastAPI**. Для запуска проекта на локальном компьютере выполните следующие шаги:

### 1. Подготовка окружения
В терминале вашей IDE установите необходимые легковесные библиотеки веб-сервера:
```bash
pip install fastapi uvicorn pydantic
```

### 2. Запуск генератора датасета
Скрипт автоматически создаст тестовые диалоги на основе бизнес-логики компании:
```bash
python generate_mock_data.py
```

### 3. Запуск теста производительности GPU
Запуск бенчмарка для проверки математических результатов ускорения:
```bash
python benchmark.py
```

### 4. Запуск API-сервера чат-бота
Выполните команду для поднятия локального веб-сервера:
```bash
python app.py
```
*После этого сервер начнет принимать запросы по адресу `http://127.0.0.1:8000`.*
Прямо в этом же окне браузера, где у вас сейчас горит надпись {"detail":"Not Found"}, кликните в адресную строку и допишите в самый конец слово /docs

### 🚀 Интерактивное тестирование (POST-запросы)
1. Перейдите в браузере по адресу интерактивной документации: **http://127.0.0**
2. Разверните вкладку эндпоинта **`POST /api/v1/chat`** и нажмите **Try it out**.
3. Чтобы проверить триггеры бизнес-логики, очистите окно ввода (Request body) и отправьте JSON-тест:
```json
4. Заполните текстовые поля:
	• user_info: Ivan, ID: 777
	• message: error

```
5. Нажмите **Execute**. Сервер обработает запрос и вернет официальный  регламент поддержки абонентов «Вашей компании » со статусом **200 OK**.
text
Please write your ID and Name: Ivan, ID: 777

AI Assistant [NAO NSK Tricolor (AI Assistant)]: Receiver issue detected. Please unplug the device from the power outlet for 10 seconds. If the error persists, we will send an activation command to your ID.

Данный алгоритм можно использовать под любые задачи для различных компаний.
